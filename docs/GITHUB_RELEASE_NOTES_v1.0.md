# Kirby's Dream Land - Level Select v1.0

Initial public release.

- Select any of the five stages directly from the title screen with A.
- Toggle Normal Mode / Extra Mode with B.
- Open the original Configuration Mode with Select.
- Start launches the selected stage and mode.
- Original secret codes are preserved.
- Includes BPS (recommended) and IPS patches.

No ROM is included. See README.txt for patching instructions and source-ROM hashes.
