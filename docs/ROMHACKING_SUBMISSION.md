## Full description

This quality-of-life hack adds a simple level select directly to the title screen of Kirby's Dream Land.

Press A to cycle through all five stages, B to toggle between Normal Mode and Extra Mode, Select to open the original Configuration Mode, and Start to begin the selected stage and mode. Configuration settings are retained when returning to the title screen.

The game's original Extra Game and Configuration Mode secret-button combinations remain functional. The hack is otherwise intended to preserve the original game: stage layouts, music, physics, and normal gameplay mechanics are unchanged.

The included release contains both BPS and IPS patches. BPS is recommended because it validates the clean source ROM.
